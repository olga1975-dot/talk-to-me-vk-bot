# Talk to me — VK-бот для разговорной практики английского

Рабочий MVP для детей 5–15 лет в сообщениях сообщества ВКонтакте. Бот знакомится с ребёнком, подбирает сложность по возрасту и уровню, поддерживает контекстный диалог через Kie.ai Chat API, мягко исправляет полезные ошибки и предлагает подсказки. Есть текстовый режим, два синтезированных голоса и распознавание голосовых сообщений.

## Возможности

- регистрация: имя, возраст 5–15, уровень и интересы;
- темы: животные, игры, спорт, музыка, фильмы, повседневная жизнь и свободная тема;
- контекстная генерация реплик ИИ вместо набора заготовленных вопросов;
- история и настройки хранятся в SQLite и не теряются при смене режима;
- для детей 10+ — просьба ответить предложением вместо одного слова;
- повтор текущего вопроса при бессмыслице или запрещённой теме;
- постоянная кнопка `💡 Help` с примерами, созданными ИИ;
- `💬 Text`, `👩 Female voice`, `👨 Male voice`;
- распознавание голоса и синтез речи через Kie.ai;
- защита кредитов: реальные ИИ-вызовы разрешены только `AUTHORIZED_VK_ID`, остальные видят демо-заглушку;
- команды `/start`, `/topics`, `/mode` и кнопки меню VK.

## Быстрый запуск

1. Создайте сообщество VK, включите сообщения и Bots Long Poll API.
2. В управлении сообществом создайте ключ доступа с правом управления сообщениями.
3. Узнайте числовой ID сообщества и создайте API-ключ Kie.ai.
4. Установите Python 3.11+ и выполните:
3. Установите Python 3.11+ и выполните:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
```

5. Заполните `VK_GROUP_TOKEN`, `VK_GROUP_ID` и `KIE_API_KEY` в `.env`.
6. Запустите:

```bash
python vk_bot.py
```

Бот использует Bots Long Poll API, поэтому домен и HTTPS для локального запуска не нужны. Для сервера достаточно запустить ту же команду в Docker, systemd или process manager. Одновременно должен работать только один экземпляр бота.

## Проверка без Telegram и платного API

```bash
python -m unittest discover -s tests -v
python -m compileall vk_bot.py talk_to_me
```

## Важно для использования с детьми

- Голосовые ответы помечены как синтезированные ИИ.
- Фильтр MVP снижает риск нежелательных тем, но не является гарантией абсолютной безопасности. Перед реальным запуском нужны тесты модерации, журнал инцидентов, политика хранения/удаления данных и согласие родителя или школы.
- В базе сохраняются профиль и текст диалога. Голосовые файлы скачиваются во временный файл и удаляются сразу после распознавания.
- Для самых младших детей рекомендуется участие взрослого.

## Структура

- `vk_bot.py` — VK Long Poll, клавиатуры и сценарий регистрации;
- `talk_to_me/ai.py` — Kie.ai, распознавание и TTS;
- `talk_to_me/db.py` — SQLite-профили и история;
- `talk_to_me/guardrails.py` — локальная проверка ответа;
- `talk_to_me/prompts.py` — педагогические и безопасностные инструкции;
- `tests/` — тесты критичных локальных правил.
