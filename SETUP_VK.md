# Подключение Talk to me к VK с нуля

Названия пунктов могут немного отличаться в мобильной и компьютерной версии VK. Удобнее выполнять настройку с компьютера.

## 1. Создайте сообщество

1. Откройте VK и перейдите в раздел **Сообщества**.
2. Нажмите **Создать сообщество**.
3. Выберите подходящий тип, например **Публичная страница** или **Бизнес**.
4. Название: `Talk to me`.
5. Тематика: образование или дополнительное образование.
6. Завершите создание.

## 2. Включите сообщения сообщества

1. Откройте созданное сообщество.
2. Перейдите в **Управление**.
3. Найдите раздел **Сообщения**.
4. Включите **Сообщения сообщества**.
5. При наличии поля приветствия можно написать: `Hi! Напишите «Начать», чтобы практиковать английский.`

После этого на странице сообщества должна появиться кнопка **Написать сообщение**.

## 3. Создайте ключ доступа

1. В управлении сообществом откройте **Работа с API**.
2. Перейдите на вкладку **Ключи доступа**.
3. Нажмите **Создать ключ**.
4. Включите право **Управление сообщениями сообщества**. Если интерфейс предлагает отдельное право на документы, также включите его — оно нужно для голосовых ответов.
5. Подтвердите действие кодом или другим способом, который предложит VK.
6. Скопируйте созданный ключ. Это значение для `VK_GROUP_TOKEN`.

Ключ нельзя публиковать, вставлять в отчёт или отправлять посторонним. Он даёт программе право отвечать от имени сообщества.

## 4. Включите Bots Long Poll API

1. В разделе **Работа с API** откройте вкладку **Long Poll API**.
2. Переключите Long Poll API в состояние **Включено**.
3. Оставьте предложенную актуальную версию API.
4. Откройте **Типы событий**.
5. Включите событие **Входящее сообщение** (`message_new`).
6. Сохраните настройки.

Callback API и адрес сервера для этого проекта настраивать не нужно.

## 5. Найдите ID сообщества

Нужен числовой идентификатор без слова `club` и без минуса. Обычно он отображается в управлении сообществом или в адресе вида `vk.com/club123456789`.

Для такого адреса значение будет:

```env
VK_GROUP_ID=123456789
```

Если у сообщества красивый буквенный адрес и ID не виден, временно откройте раздел управления/основной информации либо скопируйте ссылку на запись сообщества — в ней обычно присутствует числовой ID после минуса. В `.env` минус указывать не нужно.

## 6. Подготовьте файл `.env`

В папке проекта скопируйте `.env.example` в `.env` и заполните три строки:

```env
VK_GROUP_TOKEN=ваш_секретный_ключ_сообщества
VK_GROUP_ID=123456789
KIE_API_KEY=ваш_секретный_ключ_Kie.ai
AUTHORIZED_VK_ID=2840329
AUTHORIZED_TG_ID=328761045
```

Кавычки не нужны. Пробелы вокруг знака `=` не ставьте.

## 7. Установите и запустите

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python vk_bot.py
```

macOS или Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python vk_bot.py
```

В окне появится строка `Talk to me VK bot started`. Не закрывайте окно во время демонстрации.

## 8. Проверьте

1. Откройте страницу сообщества как пользователь.
2. Нажмите **Написать сообщение**.
3. Отправьте `Начать`.
4. Пройдите регистрацию и выберите тему.
5. Проверьте `💡 Help`, `📚 Topics` и `🎙 Mode`.

Если бот молчит, проверьте: включены ли сообщения сообщества, Long Poll API и событие «Входящее сообщение»; правильно ли указаны ID и токен; продолжает ли работать окно с `python vk_bot.py`.
